# Free Imot.bg Scraper & Google My Maps Exporter

A multi-threaded Python tool designed to scrape, evaluate, and geocode real estate listings from [Imot.bg](https://www.imot.bg).

It features keyword-based property evaluation, price/size extraction, duplicate elimination, and automated GPS geocoding via OpenStreetMap's Nominatim API. Overlapping listings in the same village or town are automatically arranged using radial GPS jittering, producing a CSV file ready to import directly into Google My Maps.

---

## Features

* **Multi-Threaded Scraping:** Concurrent execution (`ThreadPoolExecutor`) for fast data extraction.
* **Property Presets:** Built-in scoring rules and red-flag filters for both **land plots** (`land`) and **houses/villas** (`houses`).
* **Automated Geocoding:** Uses OpenStreetMap Nominatim with strict settlement layer filtering to prevent false matches on street names or local monuments.
* **Radial GPS Jittering:** Spreads out duplicate pins in the same village into a circular pattern so every property remains individually visible and clickable on Google My Maps.
* **Sofia & Pernik Region Support:** Pre-configured regional metadata and fallback coordinates for unresolved locations.
* **Modular CLI:** Run scraping and CSV map exporting together or as separate pipeline steps.

## Quick Start & Usage

The script is executed using the `imot_analyzer.py` CLI interface.

### 1. Scrape & Export Map CSV in One Command

Scrape land listings in Pernik region, save the JSON report, and automatically generate a jittered CSV for Google My Maps:

```bash
python3 imot_analyzer.py scrape \
  --url "https://www.imot.bg/obiavi/prodazhbi/oblast-pernik/partsel?price_max=15000&regulation=1&sort=3" \
  --type land \
  --region pernik \
  --out-json pernik_land_report.json \
  --export-map \
  --out-csv pernik_land_map.csv

```

---

### 2. Scrape Only (JSON Report)

Fetch and score house listings without making geocoding API calls:

```bash
python3 imot_analyzer.py scrape \
  --url "https://www.imot.bg/obiavi/prodazhbi/oblast-sofiya/kashta?type_home=11~&price_max=60000&sort=3" \
  --type houses \
  --region sofia \
  --out-json sofia_houses_report.json

```

---

### 3. Export Map CSV from Existing JSON (Standalone)

Convert a previously saved JSON report into a Map CSV without re-scraping Imot.bg:

```bash
python3 imot_analyzer.py export \
  --in-json sofia_houses_report.json \
  --out-csv sofia_houses_map.csv \
  --region sofia

```

## Command Line Reference

### `scrape` Subcommand Options

| Argument | Choices | Description |
| --- | --- | --- |
| `--url` | *URL String* | Imot.bg search result URL. |
| `--type` | `land`, `houses` | Evaluation preset for scoring and filters. |
| `--region` | `sofia`, `pernik` | Target region for fallbacks and cleaning. |
| `--out-json` | *File Path* | Output path for the detailed JSON report. |
| `--export-map` | *Flag* | Optional. Triggers automatic CSV map generation. |
| `--out-csv` | *File Path* | Required if `--export-map` is passed. Output CSV path. |
| `--workers` | *Integer* | Number of concurrent threads (Default: `6`). |

### `export` Subcommand Options

| Argument | Choices | Description |
| --- | --- | --- |
| `--in-json` | *File Path* | Input JSON report generated by `scrape`. |
| `--out-csv` | *File Path* | Destination CSV file path for Google My Maps. |
| `--region` | `sofia`, `pernik` | Target region for fallback coordinates. |

## Importing into Google My Maps

1. Open [Google My Maps](https://www.google.com/maps/about/mymaps/) and create a new map.
2. Click Import under the layer panel and select your generated CSV file (e.g., `pernik_land_map.csv`).
3. When prompted to "Choose columns to position your placemarks", check `Latitude` and `Longitude`.
4. When prompted to "Choose a column to title your markers", select `Title` or `Location`.
5. Once all listings populate on the map as individual pins, click "Uniform style" (or click the paint roller icon next to All items in the layer panel).
6. Set Group places by to Score.
7. Select Ranges to automatically color-code your pins into numerical score brackets (e.g., negative/low scores in red, top matches in green/blue).
